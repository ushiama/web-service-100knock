# テーマ8：非同期通信とフロントエンド連携

[← テーマ7](theme7.md) ｜ [概要](../README.md) ｜ [テーマ9 →](theme9.md)

本テーマでは，フロントエンドからのAPIアクセスや非同期通信の基礎，取得データの動的表示，およびエラー処理の基礎について習得する．
ブラウザ標準のfetch APIとasync/awaitを用い，現代的なWebアプリケーション開発に必要なスキルを身につけることを目指す．

> 80〜85・88はバニラJavaScriptで取り組む（全員共通）．86・87はテーマ7で選んだトラック（A：React／B：Streamlit）で取り組むこと（87はバニラJSでもよい）．

### 80. Promiseとasync/awaitの基本

- `setTimeout`を使って一定時間後に解決するPromiseを作成し，then/catchで処理するサンプルコードを作成すること．
- 同じ処理をasync/await（`try...catch`）で書き直し，両者を比較すること．

**提出物**
- JavaScriptコード
- コンソール出力のスクリーンショット

**提出物**

### 86. UIフレームワークでのAPIからのデータ取得

- APIからデータを取得し，リスト表示する画面を，テーマ7で選んだトラックで作成すること．
- **A（React）**：`useEffect` と fetch を用いる．読み込み中・エラーの状態も `useState` で管理して表示すること．
- **B（Streamlit）**：`requests`（または `httpx`）でAPIを呼び出す．読み込み中は `st.spinner`，失敗時は `st.error` で表示し，`@st.cache_data` で取得結果をキャッシュすること．
- 82（バニラJS）と比べ，書き方の違いを一言まとめること．

**提出物**
- 該当するソースコード
- 表示画面のスクリーンショット

### 89. CORS（クロスオリジン）の調査と体験

- CORS（Cross-Origin Resource Sharing）の仕組み，なぜ発生するのか，どう対策するのかを調査し，200字程度でまとめること．
- 87で，ブラウザ側のJavaScript（バニラJSまたはReact）とAPIを別ポートで動かしたときに実際にCORSエラーを発生させ，サーバ側の設定（`cors`ミドルウェア等）またはViteのプロキシ設定で解決すること．
- 87をStreamlitで実装した人は，CORSエラーが**起きない**ことを確認してその理由（APIを呼び出しているのはブラウザかサーバか）を説明したうえで，バニラJSで別ポートからAPIを呼び出してCORSエラーを体験すること．

**提出物**
- README.mdへのまとめ
- エラー発生時と解決後のスクリーンショット
